# Crypto Price Analyzer v3

## Project Goal

The goal of this project is to build a Python application that allows users to input cryptocurrency data, store it in a file, and perform basic analysis on stored data.

## Requirements

- Allow the user to input cryptocurrency names and prices
- Store the data persistently in a file
- Read and load stored data from the file
- Calculate average, maximum, and minimum prices
- Identify the cryptocurrencies with the highest and lowest values
- Display all results clearly in the console

## Features

- Data persistence using file storage
- Ability to reuse previously stored data
- Basic statistical analysis
- Structured data handling using lists and dictionaries

## How to use

1. Run the program:
   python main.py

2. Enter cryptocurrency names and prices when prompted

3. The program will save the data and display analysis results

4. Stored data can be reused in future executions
